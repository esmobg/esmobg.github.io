# esmobg.github.io

Personal page of **Ismail Ismail** (esmobg): WordPress developer and accessibility QA.
It lists all public GitHub projects in **Bulgarian** (default) and **English**.

- 🇧🇬 https://esmobg.github.io/
- 🇬🇧 https://esmobg.github.io/en/

The page is generated from the GitHub API by a GitHub Action **every day**, so new public repositories appear automatically.

## How it works

| Path | Purpose |
| --- | --- |
| `build.py` | Fetches the public repositories, merges `data/projects.json`, renders both languages into `_site/` (Python 3.9+, standard library only) |
| `templates/page.html` | The page template (`{{t.key}}` = translated text, `{{...}}` = generated blocks) |
| `i18n/bg.json`, `i18n/en.json` | All interface text. Both files must have the same keys (the build checks this) |
| `data/projects.json` | Per-project overrides: Bulgarian and English names and descriptions, order, group (`featured` or `archive`), tags, icon or logo, card image and its alt text, live link, status |
| `tools/screenshot.py` | Makes an 800×500 WebP card image from a URL or a screenshot (run by hand, not by the daily build) |
| `assets/` | CSS (same design system as the [Accessibility Guardian website](https://esmobg.github.io/Accessibility-Guardian/)), theme-toggle script, monogram |
| `.github/workflows/pages.yml` | Builds and deploys on push, daily at 04:17 UTC, and on demand |

A new repository without an entry in `data/projects.json` is still shown: in **Featured** if it has content, or in **Learning & archive** if it is archived or empty. Its GitHub description is used in both languages until a translation is added.

## Add or update a project

Add an entry to `data/projects.json`:

```json
"my-repo": {
	"order": 8,
	"group": "featured",
	"icon": "code",
	"name": { "bg": "Моят проект", "en": "My project" },
	"description": { "bg": "Кратко описание.", "en": "Short description." },
	"tags": ["WordPress", "PHP"],
	"live": "https://example.com/"
}
```

Icons: `access`, `trophy`, `theme`, `radio`, `timer`, `cards`, `calculator`, `code`. A project with its own logo can use `"logo": "assets/img/projects/<name>.png"` instead: a square PNG made for 4x screens (for example 192×192), shown on white in place of the icon. Use `"hidden": true` to hide a repository.

### Card images

Every project card has a picture at the top:

- **Screenshot**: `"image": "assets/img/projects/<name>.webp"` (or `{ "bg": ..., "en": ... }` for a picture per language) and `"image_alt": { "bg": ..., "en": ... }`. The alt text says what the screenshot shows; the build stops if it is missing. Images are 800×500 WebP (16:10, made for 2x screens) and are served from this site, because the Content Security Policy only allows images from `'self'`.
- **Cover**: a project without `image` (including a new repository with no entry) gets a cover generated by `build.py`: the hero gradient, the project's icon, name and tags. It is decorative (`alt=""`), because the card already has the same text.

Make or refresh a screenshot with `tools/screenshot.py` (needs Pillow and Chrome or Chromium; the daily build does not run it):

```bash
python tools/screenshot.py https://example.com/ assets/img/projects/example.webp
python tools/screenshot.py path/to/screenshot.png assets/img/projects/example.webp
```

## Brand

| | |
| --- | --- |
| Logo | `assets/img/logo-full.svg` (monogram + wordmark), `logo-monogram.svg`, `logo-wordmark.svg`. All are vector tracings of the original `brand/logo-original.webp` and use `fill="currentColor"`, so the page sets their colour per theme |
| Favicon | `assets/img/favicon.svg`: the monogram, brand blue on light, `#8fb0ff` in dark mode |
| Social image | `assets/img/og-image.png` (1200×630), rendered from `brand/og-image.html` |
| Brand blue | **#2356EB**: links, buttons and the logo on light backgrounds (5.8:1 on white) |
| Dark theme accent | **#8FB0FF** (8.8:1 on the dark background); the logo is white |
| Hero | Gradient from `#0D1B4D` to `#1D3FAE`; the worst-case text contrast over the gradient is 6.98:1 |

## Preview locally

```bash
GITHUB_TOKEN=$(gh auth token) python build.py
python -m http.server 8000 --directory _site
# open http://127.0.0.1:8000/ and http://127.0.0.1:8000/en/
```

## Accessibility

The page targets **WCAG 2.2 AA** and is checked with axe-core in both languages, in light and dark themes, on desktop and mobile:
- correct `lang` attributes, including names and descriptions in the other language;
- skip link and landmarks;
- visible focus and AA contrast in both themes;
- targets of at least 44 px;
- no reliance on JavaScript;
- respects reduced-motion and forced-colours preferences.

# esmobg.github.io (на български)

Лична страница на **Исмаил Исмаил** (esmobg) – WordPress разработчик и консултант по достъпност. Показва всички публични проекти в GitHub на български (по подразбиране) и на английски. Страницата се генерира автоматично всеки ден от GitHub API, така че новите публични хранилища се появяват сами. Преводите на имената и описанията на проектите се добавят в `data/projects.json`, а текстовете на интерфейса – в `i18n/bg.json` и `i18n/en.json`. Всяка карта има картинка: скрийншот (`image` и `image_alt` на двата езика в `data/projects.json`, направен с `tools/screenshot.py`) или корица, която `build.py` генерира сам, ако проектът няма скрийншот.
